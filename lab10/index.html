4. Design Reflection

I extended my Lab 9 geospatial GDP visualization by adding voice interaction. The main commands are “Show [region],” “Highlight [country],” and “Reset.” These commands support regional filtering, country lookup, and navigation without requiring precise mouse selection. This is useful on a world map because some countries are visually small and can be difficult to click accurately. The voice commands call the same filtering and highlighting functions used by the conventional controls, so the visualization behavior remains consistent across input methods. I also show visible feedback for both the recognized speech and the resulting action. Mouse interaction, a region dropdown, a country text box, and reset buttons remain available as fallback controls. The main limitation is speech-recognition reliability: pronunciation, background noise, browser support, and ambiguous country names can lead to recognition errors. For privacy, the microphone is never started automatically and requires an explicit button click.
