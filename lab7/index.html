Lab 7 — Animated Temporal Commercial Network

Node color = sector; node size = current transaction volume; link width = transaction amount; link color = transaction type.

Day 1

Temporal Network Observations

1. How does overall network connectivity change across the 60 days?
Connectivity changes across the period. Some days have many active links, while others have a visibly sparser network.

2. Which companies become more commercially active over time?
Companies whose nodes repeatedly grow larger and maintain several active connections appear more commercially active.

3. Are there periods with separate clusters?
Some days form smaller groups rather than one fully connected network, indicating temporary clusters.

4. Which relationships appear, disappear, or become stronger?
Links appear and disappear as time changes. Thicker links indicate larger transaction amounts.

5. Does the network become more or less cross-regional?
Cross-regional connectivity varies across the 60 days depending on which companies are actively connected.
