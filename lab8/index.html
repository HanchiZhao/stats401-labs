5. Semantic Findings

6. Design Description

The bulletin was divided into paragraph-sized or short policy passages while preserving page and inferred chapter, section, and subsection metadata. After cleaning duplicate or malformed text, each passage was encoded with the all-MiniLM-L6-v2 sentence-transformer model using normalized embeddings. K-means clustering was applied to the original high-dimensional embeddings, while characteristic TF-IDF terms and representative passages were used to interpret the resulting clusters. UMAP projected the semantic vectors into two dimensions using cosine distance so that nearby passages tend to have related meanings.

In the semantic map, position represents the two-dimensional embedding, color identifies semantic topic, and circle size encodes passage length. Search, formal-section filtering, semantic-topic filtering, zooming, and panning support exploration at different levels of detail. Clicking a passage keeps its full metadata and text visible while highlighting its nearest semantic neighbors. The Topic × Bulletin Section matrix complements the map by summarizing how semantic topics are distributed across the bulletin's formal structure. Clicking a matrix cell highlights the matching map passages, directly coordinating the two views. The main limitation is that UMAP is a two-dimensional approximation and cluster labels simplify complex themes, so interpretation should always be checked against the underlying passages rather than inferred from map position alone.
