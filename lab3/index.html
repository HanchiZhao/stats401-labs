Lab 3: Web Data Acquisition

Dataset Description

The dataset contains 1,000 book records collected from Books to Scrape, a website designed for web-scraping practice.

Source: Books to Scrape

Acquisition method: Python requests + BeautifulSoup

Pagination: 50 catalogue pages were requested automatically.

Rate limiting: The script waits one second between repeated requests.

Attributes: title, price, star rating, availability, source page, and product URL.
